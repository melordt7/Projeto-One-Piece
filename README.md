# 🏴‍☠️ One Piece Wiki

Um projeto desenvolvido para praticar **HTML**, inspirado no universo de **One Piece**.

O objetivo deste projeto é colocar em prática os conceitos aprendidos durante meus estudos, criando um site com informações sobre o anime de forma organizada e interativa.

---

## 📖 Páginas do projeto

- 🏠 Página Inicial
- 👤 Personagens
- 🍈 Akuma no Mi
- 🏴 Tripulações
- 🗺️ Ilhas (Mapa Interativo)

---

## ✨ Funcionalidades

- Navegação entre páginas
- Tabelas em HTML
- Imagens
- Áudios
- Image Map (`<map>` e `<area>`)
- Iframes para exibir informações das ilhas
- Links internos

---

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3 (básico)
- JavaScript (apenas para pequenas interações)

---

## 📚 Objetivo

Este projeto foi criado exclusivamente para fins de estudo.

Durante o desenvolvimento busquei praticar:

- Estruturação de páginas HTML
- Organização de arquivos
- Semântica HTML
- Criação de tabelas
- Navegação entre páginas
- Uso de mapas de imagem
- Inserção de imagens e áudios
